# 利用状況レポートの概要

Premium Learning サブスクリプションの利用状況レポートについて説明します。これには、対象となる学習アクティビティ、リクエスト可能なユーザー、含まれる履歴データの量、現在のレポートと以前のレポートの違いなどが含まれます。


## 利用状況レポートとは？

利用状況レポートは、登録、コースの完了、出席、認定、トレーニングの全体的な利用状況など、学習活動の組織全体のビューを提供します。

## 誰が利用状況レポートを受け取りますか？

利用状況レポートは、リクエストに応じて、Premium Learning サブスクリプションを管理または管理する組織のエンタープライズ連絡窓口（POC）で入手できます。 個々の学習者はこのレポートを受け取りません。

## 各月次レポートにはどの程度の履歴データが含まれますか？

各月次レポートは累積的で、2026年6月から利用可能なすべてのデータが含まれます。 将来のレポートはすべて前のレポートに基づいて作成されるため、過去と現在の学習活動を1つのレポートで表示できます。 2026年6月は、現在の学習プラットフォームへの移行を示しているため、以前のプラットフォームのデータはこれらのレポートに含まれていません。

## なぜ、2026年6月以前のデータがレポートに含まれていないのか？

月次利用率レポートには、2026年6月から現在の学習プラットフォームのデータが含まれます。 従来のプラットフォームの履歴データは、別のレポートで確認できます。 エンタープライズの連絡先は、[お問い合わせ](https://adobe.service-now.com/adls?category=10)までにコピーをリクエストできます。

## 新しい利用状況レポートが以前のレポートと異なる理由

新しい利用状況レポートは、従来のプラットフォームとは異なるデータモデルを使用する、現在の学習プラットフォームから生成されます。 その結果、一部のフィールドとデータポイントが変更されました。

また、更新されたレポートには、完了情報の詳細や学習者の不参加情報の可視化など、以前は利用できなかった追加のインサイトも含まれており、組織の学習活動をより包括的に把握することができます。
