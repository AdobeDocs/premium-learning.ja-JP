# サブスクリプションのメリットと更新

オンデマンドエデュケーションから実践的な学習、エキスパートによるサポートまで、Premium Learning サブスクリプションとPremium Learning + プライベートトレーニング サブスクリプションに含まれる利点をご確認ください。 組織がサブスクリプションを更新して、学習コンテンツへの中断のないアクセスを維持する方法について説明します。

## Premium Learning サブスクリプションにはどのようなメリットが含まれていますか？

**Premium Learning サブスクリプションは次のアクセス権を提供します：**

- Adobe Adobeの主要な学習プラットフォームに、全社的にアクセス
- オンデマンドのエデュケーションビデオへの無制限アクセス
- ハンズオンエクササイズやラボ向けの学習環境へのアクセス
- ペルソナや業界別にパーソナライズされたコホートベースの学習ジャーニー
- すべてのバーチャル・パブリック・ソート・リーダーシップ・セッション（イノベーション・ワークショップ）へのアクセス
- トラブルシューティングや特定の環境に関する質問のための、コホート後の1:1のエキスパートによる指導へのアクセス
- Adobe認定バウチャーへの無料アクセス（以下のメモを参照）

**Premium Learning + Private Training サブスクリプションでは、次のアクセス権を提供します：**

- Adobe Adobeの主要な学習プラットフォームに、全社的にアクセス
- オンデマンドのエデュケーションビデオへの無制限アクセス
- ハンズオンエクササイズやラボ向けの学習環境へのアクセス
- ペルソナや業界別にパーソナライズされたコホートベースの学習ジャーニー
- すべてのバーチャル・パブリック・ソート・リーダーシップ・セッション（イノベーション・ワークショップ）へのアクセス
- トラブルシューティングや特定の環境に関する質問のための、コホート後の1:1のエキスパートによる指導へのアクセス
- Adobe認定バウチャーへの無料アクセス（以下のメモを参照）
- パーソナライズされたプライベートトレーニング
- フェイルプルーフ環境で練習するためのオープンサンドボックスへのアクセス

>[!NOTE]
>
> 無料の認定バウチャーは、すべてのアクセスまたはオンデマンドの学習登録ユーザー（以前はAdobe デジタルラーニングサービスを利用していたユーザー）は利用できません。

## 私の学習サブスクリプションへのアクセスは、まもなく終了します。 学習コンテンツへのアクセスを維持するにはどうすればよいですか？

お客様の学習サブスクリプションとコンテンツに引き続き中断なくアクセスするには、お客様の組織からAdobe Account Managerに連絡してください。 ガイド付きで更新可能なオプションを提供します。
