# コホート – 概要

Adobe Premium Learningコホートを成功に導くために必要なあらゆる能力が揃っています。 リンクされたトピック名（各項目の最初の単語）を選択して、そのセクションに移動します。

* [ コホート構造](/help/main-guide/cohorts/cohort-structure.md)：毎週のライブセッション、自習型モジュールとクイズ、Capstone Challenge、計画する時間など、コホートの仕組みについて説明します。
* [参加の期待](/help/main-guide/cohorts/participation-expectations.md)：週2回のライブセッション出席、自習型モジュールやクイズ、Capstone Challengeなど、コホートを完了するために必要なことを理解します。
* [登録と設定](/help/main-guide/cohorts/enrollment-and-setup.md)：確認メール、ライブセッションへの招待、事前作業、サンドボックスへのアクセス、ディスカッションボードの設定など、登録後に期待できることについて説明します。
* [学習ジャーニー](/help/main-guide/cohorts/learning-journey.md)：参加者の追跡方法、クイズとCapstone Challengeを利用してコースを進める方法、コホートの最後に期待する内容を確認します。
* [ コホートライブセッションの必要システム構成](/help/main-guide/cohorts/cohort-live-session-system-requirements.md): ライブセッションのAdobe Connect、ハードウェア、ソフトウェアの要件を確認します。
* [ コミュニティ ](/help/main-guide/cohorts/community.md): **[!UICONTROL マイハブ]**&#x200B;のディスカッションボードを通じて、コホート、インストラクター、ファシリテーターとつながることができます。
* [ コホートサポート ](/help/main-guide/cohorts/support.md)：不足しているカレンダーの招待状を検索し、**[!UICONTROL マイラーニング]**&#x200B;からライブセッションを起動し、サンドボックス環境とAdobe Connectのヘルプを表示します。
