# コホート構造

## コホートの構造化は？

**ライブセッション**

毎週、Adobeのエキスパートが主催する2つの90分間のライブセッションに参加し、Adobeソリューションについて詳しく解説します。 また、グループディスカッションやインタラクティブなアクティビティを通じて、コホート内の他のメンバーとつながる機会も提供されます。 また、ベストプラクティスや実際のユースケースを共有するゲストスピーカーが登場することもあります。

**自分ペースのアクティビティ**

ライブセッションの合間には、読み物、動画、実践的な演習などのセルフガイド付きのオンラインモジュールを使用して、学習していることを実践できます。 各モジュールの後、短いクイズで理解を確認できます。 オンライン学習やクイズを完了するには、週に2～4時間予約することをお勧めします。

**Capstone Challenge**

コホートの一部として、Capstone Challenge プロジェクトで同僚のグループと共同作業を行うこともできます。 これは、学んだことを実際のシナリオで実践するチャンスです。 あなたのグループは、あなたの仕事を共有し、Adobeのインストラクターや他の学習者からフィードバックを得るための短いプレゼンテーションを提供します。
