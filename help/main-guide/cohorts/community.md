# コミュニティ

## コホートのメンバー専用のサポートチャネルやフォーラムはありますか？

各Adobe Premium Learning コホートには、**ディスカッションボード**&#x200B;が用意されており、コホートのメンバーやインストラクター、ファシリテーターが、学習内容や質問などについて会話することができます。コホートディスカッションボードは、セッション以外で同僚とエンゲージするのに最適な方法です。 ディスカッションボードは、[&#x200B; マイハブ &#x200B;](https://experienceleague.adobe.com/ja/premium/home)で、コホート **の初日に**&#x200B;利用できるようになります。

**ここに表示されていない質問ですか？ [お問い合わせ](https://adobe.service-now.com/adls?category=27).**
