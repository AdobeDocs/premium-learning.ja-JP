# 学習ジャーニー

## コホートの出席状況はどのように追跡されますか？

ライブセッションへの参加のみに基づいて、出席状況が追跡されます。 リアルタイムでセッションに参加できない場合、その後の録画を視聴しても、出席記録にはカウントされません。

## ライブ参加が必要な理由？

ライブセッションは、録画では完全に再現できない機会を提供します。 ライブに参加することで、質問をしたり、議論に参加したり、インタラクティブな環境で仲間と練習したりすることができます。 各セッションへの参加は、可能な限り優先することをお勧めします。

## コホート期間中はどのように進行すればよいですか？

短いクイズは、各週の自習モジュールの一部です。 これらは、取り上げられたトピックや概念について理解を深めるのに役立ちます。

コホートの終わりに、約40の質問からなる最終的な評価クイズに答え、学習を終えます。

また、Capstone Challenge プロジェクトの完了を通じて、進捗を追跡することもできます。 このグループアクティビティは、学んだことを実際のシナリオに適用する機会を提供します。

## コホートの最後はどうなるでしょうか？

最後の週には、学習を適用するためのCapstone Challengeと、Adobe認定試験の準備のための認定準備の時間があります。

コホート完了バッジは、[自分の実績](https://experienceleague.adobe.com/en/premium/my-achievements)で利用できます。
