# 参加の期待

**ライブセッションはコホートの中核となる部分であり、週に2回の参加が予定されています。 参加は、ライブ参加のみに基づいて追跡されます。** これらのリアルタイムのインタラクティブセッションでは、Adobeの専門家と交流したり、質問したり、ディスカッションに参加したり、他の従業員と練習したりすることができます。 セッション録画はレビュー用に使用できますが、録画の視聴は出席にカウントされません。

完了クレジットには&#x200B;**Capstone プロジェクトとピア レビューが必要です。** ガイド付きキャプストーンプロジェクトを通じて習得を示します。 学習を実際の課題に適用し、体系化されたレビューセッションで他の学習者とフィードバックを交換します。 受講者は、コホート完了クレジットを受け取るために、Capstone プロジェクトを完了する必要があります。

**ライブセッションの準備とプロジェクトの完了には、セルフペースのモジュールとクイズが不可欠です。** ライブセッション間を、自分のペースで柔軟に学習できます。 非同期モジュール、実践的なラボ、ディスカッションアクティビティにアクセスして、理解を深め、実際のシナリオで主要な概念を適用できます。
