# Premium Learningのサブスクリプションがあります。 どのような学習オプションにアクセスできますか？

## コホートベースの学習

コホート学習は、専門家によるガイド付き指導、ディスカッション、現実世界のアプリケーションを融合させ、2～8週間で共通の進捗状況、コミュニティ、コラボレーションを促進します。 Adobeの専門家や他のユーザーとリアルタイムで学びましょう。 ライブセッション間の自習型アクティビティやクイズで学びましょう。 ガイド付きキャプストーンプロジェクトを通じて習得を示します。 コホートを正常に完了すると、学習者は完了バッジを取得し、認定準備に近づきます。

コホートへの参加：[行く前に知る](/help/main-guide/cohorts/overview.md)

## ライブインストラクター向けコース

アドビでは、Adobe Experience Cloud製品チームの共同開発により、エキスパートインストラクターによるライブコースを提供しています。 Premium Learningでは、インストラクターが製品サンドボックスを使用して、インタラクティブなセッションをガイドします。 各コースのスライド、アクティビティガイド、完了バッジが表示されます。

ライブ インストラクターのコースに参加する：[行く前に知る](live-instructor-course-readiness/overview.md)

## オンデマンドコース

ライブセッションに合わせて設計されたコースを利用して、自分のペースでスケジュールを確認できます。 リクエスト可能な学習サンドボックスで実践的な製品エクササイズを深く掘り下げ、ガイド付きのアクティビティ、コース資料、完了バッジでスキルを強化しましょう。
